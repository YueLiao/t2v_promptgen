LLM 配置 + 连通性测试

中转 API(yibuapi 等)与原生 API 都用同一个接口

仅用于本次测试,不会持久化。生产用法走环境变量 T2V_LLM_API_KEY 或 ~/.t2v_promptgen/config.yaml

返回首页

环境变量(持久化)

# 任选一个或多个
export T2V_LLM_PROVIDER=yibuapi
export T2V_LLM_MODEL=gemini-2.5-pro
export T2V_LLM_API_KEY=sk-...

# 或 per-profile
export T2V_LLM_API_KEY_YIBUAPI=sk-...
export T2V_LLM_API_KEY_OPENAI=sk-...

配置文件 (~/.t2v_promptgen/config.yaml)

default_provider: yibuapi
default_model: gemini-2.5-pro
profiles:
  yibuapi:
    base_url: https://yibuapi.com/v1
    api_key: $T2V_LLM_API_KEY     # 读环境变量
  openai:
    api_key: $OPENAI_API_KEY
